# Эталонные числа по облигациям

Таблица закрывает вопрос «наш расчёт верен?» единственным способом, который
что-то доказывает: сверкой с внешним источником, не зависящим от нашего кода
(спека 5.6, `PARALLEL-TRACK.md` A4).

**Пока таблица не заполнена, расчётное ядро проверено только на проводку
данных.** Тесты в `tests/test_bonds.py` и `tests/test_bondlab_iss.py` работают
на синтетических снапшотах, эталонные поля которых посчитаны тем же кодом,
который их сверяет. Такие тесты ловят регрессии и не ловят неверную конвенцию.

Заполняется руками, по одной строке за раз. Полчаса работы закрывают вопрос,
который иначе висит до первой покупки по неверной доходности.

---

## Порядок заполнения

1. Выгрузить снапшот доски и бумаг: `python -m bondlab pull TQOB --limit 30`.
2. Открыть калькулятор доходности Мосбиржи и посчитать YTM по **той же цене и
   на ту же дату**, что в снапшоте.
3. Записать строку в таблицу ниже: цена, дата, эталон, источник.
4. Прогнать `python -m bondlab verify --board TQOB` и вписать своё число.
5. Расхождение больше порога — разбирать по списку из `PARALLEL-TRACK.md` B1,
   а не подгонять формулу.

Пороги из спеки 5.6:

| Что сверяется | С чем | Порог |
|---|---|---|
| Цена и НКД | `ACCRUEDINT` с доски ISS | до копейки |
| YTM простых выпусков | калькулятор доходности Мосбиржи | 1 б.п. |
| YTM всех выпусков, дюрация | поля `YIELD`, `DURATION` с доски, **по цене из той же строки** | 5 б.п. |

## Эталонный набор

Восемь-двенадцать выпусков, покрывающих структурные случаи. Синтетические
фикстуры уже покрывают все девять форм — колонка «фикстура» показывает, какой
файл заменяется реальным снапшотом.

| ОФЗ, фикс. купон, без оферты | `SU26238RMFS4` | | | | | | | |
| ОФЗ с амортизацией | `SU46020RMFS2` | | | | | | | |
| ОФЗ-флоатер (RUONIA) | `SU29014RMFS6` | | | | только YTP | | | |

| Флоатер на ключевую ставку | `RU000A107LS1` | | | | только YTP | | | |

Для флоатеров эталоном служит доходность к ближайшей оферте или к дате
последнего известного купона: доходности к погашению у них нет ни у нас, ни по
существу (A-12).

## Что уже проверено без внешнего источника

Эти утверждения от данных не зависят и закрыты тестами:

| Утверждение | Тест |
|---|---|
| Бумага без амортизации по номиналу даёт YTM, равную купонной ставке | `test_par_bond_yield_equals_coupon_rate` |
| Цена монотонно убывает по доходности | `test_price_decreases_with_yield` |
| Цена, посчитанная по ставке, возвращает ту же ставку | `test_ytm_round_trip_through_present_value` |
| Дюрация Маколея двухлетней бумаги по номиналу = 1,909 года | `test_macaulay_duration_of_two_year_par_bond` |
| Через високосный год равенство «YTM = купон» выполняется приближённо | `test_leap_day_shifts_par_yield_slightly` |
| Неизвестный купон даёт `None`, а не ноль | `test_ytm_is_none_when_a_coupon_is_unknown` |

Ни одно из них не подтверждает конвенцию Мосбиржи. Для этого нужна таблица
выше.
